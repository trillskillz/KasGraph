# Benchmark Artifacts

Reviewed public benchmark artifacts should be committed under dated folders:

```text
docs/artifacts/benchmarks/YYYY-MM-DD/
  summary.json
  graphql-latency.jsonl
  db-growth.json
  poi-cost.json
  resource-snapshot.json
```

Do not commit raw logs or files containing secrets, private endpoints, database URLs, bearer tokens, or host-specific sensitive data.
